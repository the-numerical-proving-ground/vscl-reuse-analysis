Algorithm 3.1 (FABsum) divides the input into blocks of size b. FastSum sums each block, then AccurateSum sums the block results. Theorem 3.1 represents the computed total as an exact sum of perturbed inputs; its bound composes the backward errors of both stages as εf(b) + εa(n/b) + εf(b)εa(n/b). The proof substitutes each block's perturbed-input representation into the outer summation and multiplies the two factors.

The paper explicitly considers recursive summation as FastSum and pairwise summation as AccurateSum (the superblock case), yielding equation (3.7) to first order. This task specializes to 2^r blocks, so every outer summand traverses r pairwise additions. The local recursive stage uses γ_(b−1), and the outer pairwise stage uses γ_r. The exact composed bound γ_(b−1) + γ_r + γ_(b−1)γ_r retains the paper's product term. The finite double index (block i, entry j) is the source's flat input arranged by blocks.
